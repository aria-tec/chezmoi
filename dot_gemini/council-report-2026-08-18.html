Ringkasan Putusan Ketua Dewan (Chairman Verdict)

Diagnosis Utama: Setup Anda mengalami Context & Prompt Duplication pada skill arsitektur dan dokumentasi. Selain itu, sebagian besar plugin populer di katalog Claude adalah *vibe prompt wrappers* atau *stateful memory daemons* yang akan merusak portabilitas dotfiles chezmoi.

1. Dimana Dewan Sepakat (High Confidence)

  • Pangkas 4 dari 6 Skill Arsitektur: Memasang 6 skill arsitektur terpisah adalah over-engineering. Model modern sudah menguasai Clean/Hexagonal tanpa 5 prompt berulang.
  • Hapus Skill find-docs: 100% redundan karena Context7 CLI sudah terpasang aktif di GEMINI.md.
  • Blacklist Meta-Bundles & Gimmick: Tolak ECC, agentic-awesome-skills, caveman, ponytail karena memicu prompt collision dengan superpowers.

2. Perdebatan & Resolusi (Trade-off Resolution)

  • Memory Tools (claude-mem / mem0): DITOLAK dari dotfiles. Database/daemon lokal merusak sinkronisasi antar-mesin dan memicu halusinasi state usang. Ganti dengan MEMORY.md lokal per-proyek.
  • Code Intelligence (GitNexus): DISETUJUI. AST graph RAG memberikan pemahaman dependensi deterministik pada codebase monorepo/skala besar.
  • Design Token (ui-ux-pro-max-skill): OPSIONAL. Hanya dipasang jika Anda aktif membuat desain CSS frontend baru dari nol.

Detail Argumen & Peer Review

The Contrarian (Skeptisisme & Anti-Bloat) Purge

Setup Anda sudah mengalami context obesity parah. Sebagian besar daftar kandidat hanyalah token-drain hypeware dan placebo prompt wrappers.

1. Pangkas & Hapus: Hapus 5 dari 6 skill arsitektur. Hapus find-docs karena Context7 sudah aktif di level prompt global.

2. Tolak Keras: Memory traps (claude-mem, mem0, mempalace, ruflo) karena rentan state drift, halusinasi konteks usang, dan menambah latensi. Vibe wrappers (taste-skill, caveman, ponytail) menyedot context budget.

3. Putusan: Purge, don't hoard. Satu-satunya pengecualian adalah GitNexus jika butuh AST graph untuk repo raksasa.

The First Principles Thinker (Fundamental Architecture) Prinsip Dasar

AI coding agent hanya butuh 3 hal: Context Akurat, Eksekusi Deterministik, dan Knowledge Terkini.

Tolak Memory Tools: Single source of truth adalah Git dan codebase, bukan database chat eksternal.

Konsolidasi: Pangkas 6 skill arsitektur menjadi 1-2 skill ringkas.

Install: GitNexus (Context AST deterministik) dan ui-ux-pro-max-skill bersyarat.

The Expansionist (Capability Upside) Upside

Melihat potensi lompatan kapabilitas pada 3 frontier superpowers: Persistent Cross-Session Memory (claude-mem/mem0), Graph RAG (GitNexus), dan Design Intelligence (ui-ux-pro-max-skill).

Namun tetap menyarankan konsolidasi 6 skill arsitektur untuk membebaskan ruang context.

The Outsider (Chezmoi Ergonomics & Portability) Konsistensi Dotfiles

Menyoroti bahwa setup saat ini adalah prompt hoarding. Chezmoi dibangun untuk portabilitas dan determinisme antar-mesin.

Menyimpan memory daemons atau background state merusak sinkronisasi dotfiles. Hapus skill duplikat dan hindari menambah dependensi eksternal tanpa ROI jelas.

The Executor (Action Plan & Steps) Eksekusi

Memberikan langkah penghapusan langsung untuk 4 skill arsitektur dan dokumentasi via chezmoi rm, serta rekomendasi instalasi terfokus pada GitNexus dan UI/UX.

Catatan Kritis Peer Review (Cross-Runtime Compatibility) Wawasan Kritis

Semua reviewer sepakat pada temuan penting: Repositori dalam katalog Claude Code tidak selalu memiliki schema SKILL.md yang identik dengan Antigravity/Gemini. Jangan clone mentah ke dotfiles tanpa menyesuaikan YAML frontmatter dan struktur MCP.
